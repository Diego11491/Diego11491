## Proyectos destacados

### [FinanData TrustGate](https://github.com/Diego11491/finandata)
**Pipeline financiero con controles de calidad y publicación · IT for Banking, Interbank–UTP**

Pipeline ETL orquestado con Prefect que separa registros rechazados en cuarentena y bloquea la publicación cuando falla una regla crítica. Integra cargas con `MERGE` idempotente en Azure SQL, conciliación posterior a la carga e historial de auditoría.

- Validación de datos, enmascaramiento de PII y trazabilidad por lote y registro.
- Pruebas con pytest y ejecución de controles mediante GitHub Actions.
- Evidencias, instrucciones de ejecución y consultas de auditoría documentadas en el repositorio.

**Tecnologías:** Python · pandas · SQL · Prefect · Great Expectations · Azure SQL · pytest

### BancoCloud
**Prototipo bancario para monitoreo de riesgo transaccional · Proyecto final en equipo, IT for Banking**

Diseño de una **arquitectura híbrida multicloud AWS/core/Azure**, con Cognito, API Gateway y Lambda para el canal digital, y componentes con Python y PostgreSQL para el core simulado.

- Procesamiento de eventos en Azure con Event Hubs, ADLS Gen2 y capas Bronze/Silver/Gold.
- Validaciones de calidad, deduplicación y cuarentena antes de la promoción analítica.
- Validación local con **10 000 transacciones sintéticas**, comprobando idempotencia, trazabilidad y recuperación de eventos mediante Transactional Outbox.

**Tecnologías:** Python · PostgreSQL · AWS Lambda · API Gateway · Cognito · SAM/CloudFormation · Azure

### SmartDispatch
**Registro y automatización de solicitudes · Proyecto académico aplicado a un reto de Prosegur Alarms**

Prototipo con Power Apps, una API y PostgreSQL para registrar solicitudes de materiales y consultar su estado. Flujos de Power Automate para crear solicitudes y enviar notificaciones, con validación del recorrido completo desde el formulario hasta el registro y el correo.

**Tecnologías:** Power Apps · Power Automate · API · PostgreSQL
